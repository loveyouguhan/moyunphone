# 墨韵手机 (moyunphone)

SillyTavern 沉浸式模拟手机扩展：微信 / 朋友圈 / 推特 / 论坛 / 匿名交友 / 日历 / 数据库 / 变量管理，
支持剧情时间系统、AI 生图（NovelAI v4 多角色 + 角色一致性）、上下文总结等能力。

## 安装

1. 打开 SillyTavern，进入「扩展」面板。
2. 点击「安装扩展」，粘贴本仓库地址，确认安装。
3. 刷新页面，右下角出现手机悬浮窗即安装成功。

## 使用提示

- 在扩展设置里配置 API（可拉取模型列表）后即可在手机内生成内容。
- 生图配置支持 NovelAI（官网 / 公益站 / 自定义站点）、OpenAI 兼容、SD WebUI 与 ComfyUI。
