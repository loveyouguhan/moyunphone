Host API 版本：**v1** · 公开方法：**169** 个。

所有启用的模块默认获得下表全部能力，不需要在 manifest 里声明权限。模块内的调用形式统一为 `api.<方法>`，例如 `api.wechat.getAvatar(profileId)`。
运行时也能枚举同一份目录：`api.meta.catalog()`、`api.meta.protocols()`、`api.meta.outputConventions()`。

## 通用约定

- 查询返回深拷贝快照；列表按接口说明排序；找不到单个实体返回 null，列表返回空数组。
- 写操作返回创建或更新后的实体、受影响数量，或 { ok, message }；Promise 拒绝表示没有完成写入。
- 参数无效、实体不存在、作用域不匹配或依赖未就绪时抛出 Error；不要把错误当作成功结果处理。
- 剧情相关时间使用手机剧情时钟的 Unix 毫秒时间戳；不要用设备当前时间推断剧情顺序。
- 头像接受 https 或 data:image/*；生图返回可用于 img.src 的地址；文本中的 image###...### 与 [[生图:...]] 是宿主协议标记。
- 状态、模块存储和写入实体都属于当前 scopeId；模块存储额外按 moduleId 隔离。
- 公开 API 不返回 API Key、完整供应商配置密钥或其他宿主凭据；不要把模块设置当作密钥保险箱。
