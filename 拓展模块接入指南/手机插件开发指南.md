# 手机插件开发指南

给创作者的入门手册。你只需要一个 `.js` 文件，就能在手机里增加一个应用。
逐个接口的签名与返回值见 [`extension-api-reference.md`](extension-api-reference.md)（169 个方法，自动生成）；
模型输出协议见 [`output-protocols.md`](output-protocols.md)。
手机内也有同一份内容：拓展应用 → 开发者指南，可直接下载模板。

## 1. 五分钟做出第一个模块

新建 `hello-phone.js`：

```js
export const manifest = {
  protocolVersion: 1,
  id: 'hello-phone',
  name: '你好手机',
  version: '1.0.0',
  author: '你的名字',
  entry: 'self',
};

export default function createModule(api) {
  const root = document.createElement('section');
  const output = document.createElement('p');
  const refresh = document.createElement('button');
  refresh.type = 'button';
  refresh.textContent = '读取当前状态';
  refresh.addEventListener('click', () => {
    const state = api.state.snapshot();
    output.textContent = '联系人 ' + Object.keys(state.profiles).length + ' 位';
  });
  root.append(refresh, output);
  return { manifest, render: () => root };
}
```

手机 → 拓展应用 → 导入模块 → 选中该文件。导入成功后首页会出现一个新图标。

可导入的完整示例在 [`../examples/extensions/`](../examples/extensions/)：
Hello World、微信头像与联系人、生成回复草稿、自动解析扩展动作。

## 2. manifest 字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `protocolVersion` | 是 | 固定 `1`，不匹配会拒绝导入。 |
| `id` | 是 | 小写字母、数字、`.`、`_`、`-`，2–64 字符；同 id 视为同一模块。 |
| `name` | 是 | 显示名，最长 40 字。 |
| `version` | 是 | 自定义版本号，最长 32 字。 |
| `author` | 是 | 作者名，最长 80 字。 |
| `entry` | 是 | 单文件模块固定填 `self`（也可填当前文件名）。 |
| `description` | 否 | 列表页说明，最长 400 字。 |
| `icon` | 否 | `data:image/*` 或 https 图片，最大 512 KB。 |
| `api` | 否 | `{ mode: 'shared' \| 'profile' \| 'custom', profileName?, config? }`，决定 `api.generation.*` 用哪个通道。 |
| `generationContext` | 否 | `{ includeStorage: true }` 时，把模块存储快照注入手机生成上下文。 |
| `permissions` | 否 | 已废弃。旧模块仍可导入，但不再限制任何能力。 |

模块代码上限 1.5 MB，模块存储单键上限 256 KB。

## 3. 工厂函数与生命周期

```js
export default function createModule(api) {
  return {
    manifest,                    // 必填，id 必须与导入的 manifest 一致
    render: () => rootElement,   // 必填，返回一个 HTMLElement
    dispose: () => {},           // 可选，模块被停用/删除/切换聊天时调用
    autoParse: { /* 可选，见第 6 节 */ },
  };
}
```

- 工厂在模块启用后调用一次；`render` 在每次进入模块页面时调用。
- 定时器、事件监听、楼层触发的取消函数都放进 `dispose`，否则切换聊天后会泄漏。
- 抛出的错误会显示在模块页面上，不会影响手机其他部分。

## 4. 常用任务

按领域分组的完整目录在 `extension-api-reference.md`；下面是最常问的几件事。

**读取和设置微信头像**

```js
const avatar = api.wechat.getAvatar(profileId);            // string | null
await api.wechat.setAvatar(profileId, 'https://example.com/a.png');
await api.wechat.setAvatar(profileId, null);               // 清空
const images = api.profiles.images(profileId);             // 头像/推特头像/聊天背景/参考图/生图提示词
const twitterAvatar = api.twitter.getAvatar(profileId);    // 未设置时回退通用头像
```

头像只接受 `https://` 或 `data:image/*`，其他格式会抛错。

**联系人与会话**

```js
const contacts = api.wechat.profiles();                            // Profile[]
const { profile, conversation } = await api.wechat.addContact({ displayName: '林澈' });
await api.wechat.setRemark(profile.id, '小林');
const group = await api.wechat.createGroup('周末局', [profile.id]);
await api.wechat.deleteContacts([profile.id]);
```

**发消息与朋友圈**

```js
await api.wechat.send(conversation.id, '在吗？');                    // 进入统一回复队列
await api.wechat.sendMedia(conversation.id, 'red_packet', '恭喜发财', { amount: '88' });
await api.wechat.share({ content: '今天天气很好' });                 // 不带会话 = 发朋友圈
const moments = api.wechat.moments(20);
await api.wechat.like(moments[0].id);
```

**生成**

```js
const text = await api.generation.reply({
  messages: api.wechat.messages(conversation.id, 20).map((message) => ({
    role: message.direction === 'outgoing' ? 'user' : 'assistant',
    content: message.content,
  })),
});
await api.generation.runQueued();       // 立刻处理全部待回复内容
const json = await api.generation.generateJson({ system: '只输出 JSON', user: '...' });
```

**自己的数据**

```js
await api.storage.set('records', [{ id: 1 }]);   // 按 模块 + 当前聊天 隔离
const records = (await api.storage.get('records')) ?? [];
await api.module.updateSettings({ theme: 'dark' });   // 跨聊天的模块设置
```

**跟着正文楼层跑**

```js
const stop = api.floors.onTrigger({ every: 3, role: 'assistant' }, (floor) => {
  api.notify('第 ' + floor.floor + ' 层：' + floor.text.slice(0, 20));
});
// dispose 里调用 stop()
```

**剧情时间**

```js
api.time.now();                       // 毫秒时间戳（剧情时钟，不是设备时间）
api.time.format({ dateStyle: 'medium', timeStyle: 'short' });
await api.time.set(Date.now(), '模块手动校时');
```

## 5. 输出与错误约定

- 查询返回深拷贝快照：改它不会影响手机状态，要写就调用写接口。
- 找不到单个实体返回 `null`，列表返回空数组；不要用 try/catch 来判断“有没有”。
- 写操作返回创建后的实体、受影响数量，或 `{ ok, message }`。
- 参数无效、实体不存在、作用域不匹配、依赖未就绪都会 **抛出 Error**，所以写操作要 `await` + `try/catch`。
- 所有实体都属于当前聊天作用域；切换聊天后不要缓存旧 ID。
- 公开 API 不返回 API Key：`api.api.profiles` 只给出名称、模型和 baseUrl。

## 6. 让模型往你的模块里写数据

在返回值里声明 `autoParse`，手机每次自动解析正文时会带上你的 schema：

```js
autoParse: {
  description: '正文出现快递状态时提取一条记录。',
  prompt: '只提取已经发生的状态变化。',
  schema: { type: 'object', required: ['status'], properties: { status: { type: 'string' } } },
  validate: (value) => typeof value.status === 'string',
  apply: async (value, context) => { /* 写进 api.storage 或领域接口 */ },
}
```

顺序是 schema 校验 → `parse`（可选归一化）→ `validate`（可选）→ `apply`。
`apply` 抛错只影响这一条，其他动作照常执行，错误会出现在解析结果的 issues 里。

## 7. 导入、调试与常见错误

- 导入入口：手机首页 → 拓展应用 → 导入模块，只接受 `.js` / `.mjs`。
- 报错会显示在模块卡片或页面上；浏览器控制台里能看到完整堆栈。
- 停用模块会调用 `dispose`；删除模块会同时清理它的设置和模块存储。
- 修改代码后重新导入同一个 `id` 即可覆盖。

| 现象 | 原因 |
| --- | --- |
| “模块协议版本不兼容” | `protocolVersion` 不是 `1`。 |
| “模块文件必须默认导出工厂函数” | 没有 `export default`，也没有 `export function createModule`。 |
| “模块定义 manifest 与导入 manifest 的 id 不一致” | 工厂返回的 `manifest` 不是同一个对象/同一个 id。 |
| “头像必须是 https 地址或 data:image/\*” | 传了 `http://` 或本地路径。 |
| “微信会话不存在” | 用了别的应用的会话 ID，或该会话已被删除。 |
| 自动解析没有写入 | 模块被停用、`data` 不符合 schema，或 `apply` 抛错。 |
| 模块存储没进模型上下文 | 没有开 `generationContext.includeStorage`。 |
